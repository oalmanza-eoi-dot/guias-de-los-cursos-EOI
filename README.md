# Guías de los cursos / Guies dels cursos — EOI Barcelona Drassanes

Portal web centralizado para consultar de forma rápida, ordenada y accesible las **Guías de los cursos** (programas oficiales por idioma y nivel) y la **Oferta específica** de la **Escola Oficial d'Idiomes de Barcelona Drassanes** para el curso académico **2026-27**.

## Características principales
- **Interfaz bilingüe (Castellano / Català):** Selector superior para alternar toda la navegación y etiquetas entre ambos idiomas.
- **Buscador en tiempo real:** Filtrado instantáneo por nombre de idioma, código identificador (`DE`, `EN`, `ES`, `AR`, `JA`, `LSC`, etc.), nivel (`A1`–`C2.2`), docente u horario.
- **Estructura desplegable limpia:** Todos los bloques arrancan contraídos por defecto para evitar saturación visual y facilitar la consulta desde ordenador o móvil.
- **Cobertura completa del centro:**
  - **Idiomas (15):** Alemán, Inglés, Árabe, Catalán, Coreano, Español, Vasco, Francés, Griego, Italiano, Japonés, Neerlandés, Portugués, Ruso y Chino, enlazados a sus respectivos programas por nivel.
  - **Oferta específica (10):** Danés, Dariya, Gallego, Hebreo, Lengua de signos catalana, Persa, Polaco, Quechua, Sueco y Turco, con tabla de niveles, horarios, fechas y profesorado asignado.

## Estructura del repositorio
- `index.html` — Portada principal del portal (*Guías de los cursos / Guies dels cursos*).
- `eoicert.jpg` — Logotipo institucional del centro.
- `<idioma>/<nivel>/index.html` — Programas individuales de cada curso y nivel (por ejemplo, `espanyol/b2-2/index.html`).
